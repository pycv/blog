# 博客架构说明

> 更新时间：2026-10-26
> 适用仓库：pycv/blog（https://github.com/pycv/blog）

## 一句话

Hugo 静态站 + Stack 主题 + GitHub Actions 构建 + GitHub Pages 托管。本地只写 Markdown，push 到 `main` 即自动上线，无后端、无数据库。

## 分层结构

### 1. 内容层 `content/`

| 目录 | 用途 | 说明 |
|------|------|------|
| `posts/` | 原创文章 | tags 里习惯加「随笔」 |
| `excerpts/` | 文章摘录 | 带 `_index.md`，categories 为「摘录」 |
| `about/` | 关于页 | page bundle，入口 `index.md` |

每篇文章靠 front matter 驱动：`title / date / draft / tags / categories`。

### 2. 渲染层

- 主配置 `hugo.toml`
  - `baseURL = https://pycv.github.io/blog/`
  - `locale = zh-cn`，`enableGitInfo = true`（用 git 历史生成最后修改时间）
  - 分页 `pagerSize = 10`
  - `mainSections = [posts, excerpts]`
  - taxonomies：`category` / `tag`
  - `markup.goldmark.renderer.unsafe = true`（允许正文内嵌 HTML）
- 主题：`themes/hugo-theme-stack`（v4.0.3），以 **git submodule** 引入，源走 `gh-proxy.com` 镜像
- 覆写层 `layouts/`（7 个文件）
  - `excerpts/list.html` — 摘录列表页
  - `home.html` — 首页文章流
  - `list.html` — 通用列表
  - `_partials/article-list/default.html` — 列表项卡片
  - `_partials/head/custom.html` — 头部注入
  - `partials/pagination.html` — 分页
  - `_partials/widget/taxonomy.html` — 标签云
- 样式：`assets/scss/custom.scss`（只放差异，不 fork 主题）

### 3. 工具层

- `tools/wechat-fetch.mjs` — Playwright 版微信文章抓取（重，备用）
- 日常抓取走 skill 的轻量 Python 脚本（Mobile UA，无依赖）
- `node_modules/` 只有 playwright，已 gitignore

### 4. 构建与部署 `.github/workflows/deploy.yml`

```
push main → checkout(submodules: recursive, fetch-depth: 0)
         → Hugo 0.167.0 extended
         → hugo --minify
         → 校验 public/ 非空 + 统计页数
         → upload-pages-artifact → deploy-pages
```

- 触发：push 到 `main`，或手动 `workflow_dispatch`
- 并发组 `pages`，同一时间只跑一个部署
- `fetch-depth: 0` 是必需的：`enableGitInfo` 依赖完整 git 历史

### 5. 内容生产链路

```
链接 → link-to-article skill（判断微信/普通网页 → 抓正文）
     → 分析 + 打分 → 按模板成文
     → blog-writer skill（标签池规范化 → 命名 → 落盘）
     → git add/commit/push → CI 构建 → Pages
```

## 环境约定

| 项 | 值 |
|----|----|
| 本地 Hugo | 0.167.0 extended（2026-10-26 从 0.162.1 升级） |
| CI Hugo | 0.167.0 extended |
| 模块最低要求 | 0.157.0 extended |
| 站点地址 | https://pycv.github.io/blog/ |

**本地与 CI 版本必须保持一致**，否则会出现「本地能构建、线上报错」或反之。

## 已知坑

1. **date 不能写未来时间**。Hugo 默认 `buildFuture = false`，未来时间的文章会被静默跳过：push 成功、CI 成功，但线上 404。
2. **必须是 extended 版**。Stack 主题用 SCSS，普通版构建会报 `TOCSS: failed to transform ... you need the extended version`。
3. **主题是 submodule**。克隆时要 `--recursive`，否则 `themes/hugo-theme-stack` 为空。
4. **`public/` 和 `resources/` 不提交**，已在 .gitignore。
